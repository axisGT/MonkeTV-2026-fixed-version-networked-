# 🐒 MonkeTV 2026 | Networked Edition 📺

**Watch videos with your friends in Gorilla Tag!**

MonkeTV is a Gorilla Tag mod that adds a working TV inside Stump, allowing you to play your own videos and enjoy them with your friends.

This is the **2026 Networked Edition**, designed to bring a shared video-watching experience to Gorilla Tag.

![MonkeTV Preview](https://github.com/user-attachments/assets/bdba1b56-6081-4254-932e-405f831fc2f3)

## ✨ Features

- 📺 **In-Game TV:** Adds a TV inside Stump.
- 🎬 **Custom Videos:** Play your own MP4 video files.
- 🌐 **Networked Experience:** Watch videos with your friends.
- 📁 **Simple Video Management:** Add videos directly to the mod's video folder.
- 🐒 **Gorilla Tag Integration:** Enjoy videos without leaving the game.

## 📥 Installation Guide

Follow these steps to install MonkeTV.

### Step 1: Download MonkeTV

Download the latest version of MonkeTV from the repository's releases section.

### Step 2: Extract the Files

Find the downloaded archive and extract it using Windows Explorer, WinRAR, or 7-Zip.

![Download](https://github.com/user-attachments/assets/c510010a-9eef-4c52-a65e-c10c590cce10)

![Extract](https://github.com/user-attachments/assets/61d9676a-d5c2-490d-bf22-4fc60210bb39)

![Extracted Files](https://github.com/user-attachments/assets/067a67c9-435d-4f75-a951-95cb9f235f0a)

### Step 3: Install the Mod

Locate your Gorilla Tag installation directory.

Open the `BepInEx` folder, then navigate to `plugins`.

Copy the extracted MonkeTV mod files into the `plugins` folder.

Your installation path should look similar to this:

`Gorilla Tag/BepInEx/plugins/`

### Step 4: Add Your Videos 🎬

To play custom videos:

1. Open the MonkeTV mod folder.
2. Locate the `Videos` folder.
3. Copy your `.mp4` video files into that folder.
4. Launch Gorilla Tag.
5. Head over to Stump and find the TV!

**Supported video format:** `.mp4`

## 🌐 Watching With Friends

MonkeTV includes networked functionality intended to let players enjoy videos together in Gorilla Tag.

For the best experience, make sure everyone is using a compatible version of the mod.

## 🔧 Troubleshooting

**TV not appearing?**
- Make sure the mod files are inside `BepInEx/plugins`.
- Check that BepInEx is installed correctly.
- Restart Gorilla Tag after installing the mod.

**Videos not showing up?**
- Make sure your videos use the `.mp4` extension.
- Confirm they are inside the correct `Videos` folder.
- Try restarting the game after adding new videos.

**Videos not syncing?**
- Make sure players are using compatible versions of MonkeTV.
- Check that the mod loads correctly for everyone.
